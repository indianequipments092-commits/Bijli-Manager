# Bijli Manager - APK shell

Ye repo sirf ek baar APK banane ke liye hai. Is me app ka code nahi hai.
App ka asli code dusre repo (HTML repo) me hai, APK wahin se load karti hai.

1. `capacitor.config.json` kholo, `server.url` me apna link daalo:
   https://USERNAME.github.io/HTML-REPO-NAME/
2. Commit karo. Actions tab me "Build APK" chalega (5-8 min).
3. Run kholo > Artifacts > `bijli-manager-apk` > download > install.

Is repo ko dobara chhedna nahi padega. HTML repo update karte hi app update ho jati hai.
